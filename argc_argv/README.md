## Unreleased ##

This DIR is for the purpose of learning and testing with argc and argv.

- 0-whatsmyname.c, a program that prints its own name followed by a new line.

- 1-args.c, a program that prints the number of args followed by a new line.

- 2-args.c, a program that prints each argument followed by a new line.

- 3-mul.c, a program that multiplies two given arguments.

- 4-add.c, a program that adds together all arguments.

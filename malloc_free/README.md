## Unreleased ##

This directory is for the purpose of learning and testing "malloc" and "free" functions in C, for Holberton School learning projects. All files use malloc, to allocate memory for the arrays.

- Added file 0-create_array.c, this is a function that creates an array of chars, and initializes it with a specific char.

- Added file 1-strdup.c, this is a function that returns a pointer to a newly allocated space in memory, which contains a copy of the string given as a parameter.

- Added file 2-str_concat.c, this is a function that concatenates two strings.

- Added file 3-alloc_grid.c, this is a function that returns a pointer to a 2 dimensional array of integers.

- Added file 4-free_grid.c, this is a function that frees a 2 dimensional grid previously created by my 3-alloc_grid function.
